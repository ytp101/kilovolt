# P1 — Single-Instance Product Hardening

## Execution status

**Deferred. Do not implement P1 while completing P0.**

P1 begins only after every exit criterion in `P0.md` is complete and a new
decision explicitly authorizes more product work.

## Objective

Turn the academic, process-local MVP into a more durable and manageable
single-instance product without adding cloud multi-tenancy or distributed
operation.

## Deferred work

- [ ] Add individually configurable limits for specific users instead of only
      one shared default per-user limit.
- [ ] Persist configuration, ledgers, reservations, and transaction history in
      a durable local database.
- [ ] Define safe recovery behavior for active reservations after a crash or
      restart.
- [ ] Replace floating-point money with integer atomic monetary units or a
      decimal representation.
- [ ] Add provider-key and gateway-key rotation workflows.
- [ ] Add configurable transaction retention, filtering, and export.
- [ ] Add request-rate and concurrent-connection limits.
- [ ] Add a total streaming-duration or idle timeout after upstream headers.
- [ ] Expand and maintain the verified OpenAI pricing registry.
- [ ] Add stronger operational health/readiness reporting.
- [ ] Add backup, restore, and local upgrade guidance.
- [ ] Add automated migration and persistence tests.

## P1 exit criteria

P1 would be complete when:

1. A single Kilovolt instance can restart without losing committed spending
   state or configuration.
2. Operators can assign and change limits for individual users.
3. Monetary calculations avoid binary floating-point behavior.
4. Secrets can be rotated without rebuilding the application integration.
5. Operational limits, retention, recovery, and upgrade behavior are tested and
   documented.

## Excluded from P1

- Multiple synchronized Kilovolt replicas.
- Multiple application projects or organizations.
- Hosted SaaS accounts, SSO, or RBAC.
- Providers other than OpenAI.
- OpenAI APIs outside the supported Chat Completions surface.

Those items belong to P2 and are not required for the academic MVP.
