.env
KILOVOLT_API_KEY=kvlt_xxxxxxxxxxxxxxxxx
KILOVOLT_BASE_URL=http://127.0.0.1:8080/v1

Do not commit .env. The copy action inserts your real gateway key.

Python dependenciespip install openai python-dotenv
Python
import os

from dotenv import load_dotenv
from openai import OpenAI

load_dotenv()

client = OpenAI(
    api_key=os.environ["KILOVOLT_API_KEY"],
    base_url=os.environ["KILOVOLT_BASE_URL"],
)

response = client.chat.completions.create(
    model="gpt-4o-mini",
    messages=[{"role": "user", "content": "Hello from Kilovolt"}],
    max_completion_tokens=100,
    extra_headers={
        "X-User-ID": "local-test-user",
    },
)

# Optional: confirms the request reached OpenAI through Kilovolt.
print(response.choices[0].message.content)

local-test-user is for evaluation only. Replace it with the authenticated user ID from your backend.

TypeScript dependenciesnpm install openai dotenv
TypeScript
import "dotenv/config";
import OpenAI from "openai";

const client = new OpenAI({
  apiKey: process.env.KILOVOLT_API_KEY,
  baseURL: process.env.KILOVOLT_BASE_URL,
});

const response = await client.chat.completions.create(
  {
    model: "gpt-4o-mini",
    messages: [{ role: "user", content: "Hello from Kilovolt" }],
    max_completion_tokens: 100,
  },
  { headers: { "X-User-ID": "local-test-user" } },
);

console.log(response.choices[0].message.content);

local-test-user is for evaluation only. Replace it with the authenticated user ID from your backend.

curl
curl "$KILOVOLT_BASE_URL/chat/completions" \
  -H "Authorization: Bearer $KILOVOLT_API_KEY" \
  -H "Content-Type: application/json" \
  -H "X-User-ID: local-test-user" \
  -d '{"model":"gpt-4o-mini","messages":[{"role":"user","content":"Hello from Kilovolt"}],"max_completion_tokens":100}'
