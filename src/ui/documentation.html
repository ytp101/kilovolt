Local quick reference

Use Kilovolt from your backend

Choose your language and send an OpenAI-compatible request through the local Kilovolt gateway.

Before you start

  1. Copy your gateway keyGet it from the expanded Connect your application panel on the dashboard.
  2. Set one environment variableexport KILOVOLT_API_KEY="your-kilovolt-gateway-key"
  3. Use your trusted user identityDerive the user ID only after your backend authenticates the user.
Local base URL: http://127.0.0.1:8080/v1

Send a request

Each example uses the same gateway key and trusted accounting identity.

# Install once: pip install openai
import os
from openai import OpenAI

client = OpenAI(
    api_key=os.environ["KILOVOLT_API_KEY"],
    base_url="http://127.0.0.1:8080/v1",
)

authenticated_user_id = "user-123"  # derive from the authenticated session
response = client.chat.completions.create(
    model="gpt-4o-mini",
    messages=[{"role": "user", "content": "Hello"}],
    max_completion_tokens=100,
    extra_headers={"X-User-ID": authenticated_user_id},
)

print(response.choices[0].message.content)
// Install once: npm install openai
import OpenAI from "openai";

const client = new OpenAI({
  apiKey: process.env.KILOVOLT_API_KEY,
  baseURL: "http://127.0.0.1:8080/v1",
});

const authenticatedUserId = "user-123"; // derive from the authenticated session
const response = await client.chat.completions.create(
  {
    model: "gpt-4o-mini",
    messages: [{ role: "user", content: "Hello" }],
    max_completion_tokens: 100,
  },
  { headers: { "X-User-ID": authenticatedUserId } },
);

console.log(response.choices[0].message.content);
curl http://127.0.0.1:8080/v1/chat/completions \
  -H "Authorization: Bearer $KILOVOLT_API_KEY" \
  -H "Content-Type: application/json" \
  -H "X-User-ID: user-123" \
  -d '{
    "model": "gpt-4o-mini",
    "messages": [{"role": "user", "content": "Hello"}],
    "max_completion_tokens": 100
  }'
Why must my backend set X-User-ID?

X-User-ID is accounting identity, not authentication. Your trusted backend must set or overwrite it after authenticating the user; browsers and mobile clients must not choose arbitrary identities.

What happens next

Accepted requestKilovolt forwards the response and records tokens, calculated spend, and latency.
Budget blockedKilovolt returns HTTP 429 before spend can exceed the project or user limit.
Monitor usageOpen the local dashboard to review users and recent transactions.
