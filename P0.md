## MVP definition

Kilovolt's academic MVP is a self-hosted, single-process Rust gateway between a
trusted application backend and the OpenAI Chat Completions API. It estimates
request cost, atomically enforces one project-wide spending limit and one
default per-user limit keyed by trusted `X-User-ID`, proxies streaming and
non-streaming requests, and displays calculated usage in a local dashboard.

The MVP supports OpenAI only. It is an evaluation product, not a provider
billing system, end-user authentication service, secret manager, or
production-grade distributed gateway.

The following limitations remain part of the P0 product boundary:

- All setup, spend, and request history reset on restart.
- One process represents one implicit application project.
- Every identified user receives the same default per-user limit.
- Calculated spend is an estimate and uses `f64` values.
- Kilovolt does not authenticate the end user represented by `X-User-ID`.
